# MyDahL School Dashboard | Made by D1prezz

**MyDahl (Prodotype)**

Made Using:
Python
- Flask 
- Flask SQLALchemy 
HTML 

This project is a mini school dashboard which uses a standard CRUD interface for adding students, removing them, and updating them. It also allows you to
read these users effortlessly in a clean, formal interface. This is V1.0.0 of this app in which V.2 will be much more secure and more advanced. This is a
learning prototype and therefore is free-for-use. Please include me in your credits if you plan to use this for any reason oncesoever.
